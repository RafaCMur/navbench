How the live mode works

PyRoboSim is Python, so it cannot run on this page. Instead, planners.js is A* and RRT* written again in JavaScript, following the PyRoboSim code step by step and with the same settings. The map is the free space from PyRoboSim, saved by make web: where the centre of the robot may be, already shrunk by 15 cm for A* and by the robot radius for RRT*.

A* builds the same 5 cm grid as PyRoboSim, cell for cell, and returns the same route on all four benchmark routes. RRT* uses the same random number generator as NumPy, so a seed gives the same random points as in Python. For more than half of the benchmark runs it also returns exactly the same route. In the other runs a sine or cosine comes out different in the last digit, an edge that is exactly 50 cm long ends up just over the limit on one side and just under it on the other, and from there the two trees grow apart. Over 30 seeds the lengths come out about the same.

The times are measured in your browser, so they are not comparable with the Python times in the replay.

The world, the robot and both planners come from PyRoboSim by Sebastian Castro (MIT license). The JavaScript planners follow its code.
